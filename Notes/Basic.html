BASIC NOTES OF CSS

  1. What is CSS?
    • CSS stands for Cascading Style Sheets.
    • HTML gives the page its structure (skeleton) and description. CSS controls how the page looks (appearance).
    • Use CSS to change colors, set the background color, center text, change font size, add borders, and so on.
    • Style sheet: a place where you write properties and give them values. 
      background-color: red;   /* property: value */
color: blue;
border: 1px solid black;
  2. What does "Cascading" mean?
    • The same property can be set in more than one place. For example, the same paragraph may get background yellow, red, and blue.
    • The browser needs a rule to pick one, and that rule is the cascade.
    • Homework from the lecture: search Google for the factors the cascade depends on (for example importance, specificity, and order of the code).
  3. Three ways to add CSS
    • Inline CSS: written inside the tag with the style attribute. 
      <p style="background-color: yellow;">Hello</p>
      It is not good practice, because the code gets confusing as properties grow.
    • Internal CSS: a <style> tag inside the <head>. 
      <head>
  <style>
    h1 {
      color: green;
    }
  </style>
</head>
    • External CSS: a separate .css file. It takes two steps:
      1. Create the CSS file (for example style.css).
      2. Link it to the HTML file inside the <head>. 
        <link rel="stylesheet" href="style.css">
      This is the most used method because it keeps HTML and CSS separate (separation of concerns).
  4. CSS syntax (internal and external)
    • Selector: says which element to style (for example h1).
    • Curly brackets { }: everything inside them is the styling for that selector.
    • Property: the left side (for example color).
    • Value: the right side (for example green).
      • selector {
  property: value;
}
  5. Which CSS wins when there is a conflict?
    • Inline CSS beats internal and external CSS. In the lecture, inline yellow won over internal blue-violet and external aquamarine.
    • Internal vs external: the one written later in the code wins. Changing the order changes the winner.
    • If the same property is written twice in one place, the last one wins (red first, then aqua gives aqua).
    • !important forces a value to win over everything else. 
      p {
  background-color: blueviolet !important;
}
  6. Selectors: ways to target HTML elements
    • Element selector: use the tag name. It styles every element of that tag. 
      p {
  color: brown;
}
      This styles all <p> tags. It does not style an <article>, because that is a different tag.
    • ID selector: use # before the id name. An id belongs to one unique element. 
      #article1 {
  background-color: green;
}
    • Class selector: use . before the class name. Many elements can share one class. 
      .para-class {
  background-color: yellow;
}
      You can set many properties in one rule.
    • Group selector: use a comma to style several selectors at once. 
      p, article {
  width: 500px;
}
    • Tag + class together: p.para-class styles only <p> elements that have that class. An <article> with the same class is not affected. 
      p.para-class {
  text-align: center;
}
  7. Comments
    • In HTML: <!-- comment -->
    • In CSS: /* comment */
    • Shortcut: select the line and press Ctrl + /.
  8. Properties used in this lecture
    • background-color: sets the background color.
    • color: sets the text color.
    • border: adds a border (for example 1px solid black).
    • font-size: sets the text size.
    • text-align: center;: centers the text.
    • width: sets the width (for example 500px).
    • There are many more properties. You will learn them with practice.
  9. Quick revision
    • HTML = structure. CSS = appearance.
    • Three ways to add CSS: inline, internal, external.
    • Selectors: element, #id, .class, group with commas.
    • Inline beats internal and external. Later code beats earlier code. !important beats all.
    • Use external CSS in real projects.
