Fonts, Colors and DevTools

  1. What this lecture covers
    • Font properties: font-style, font-size, font-family, font-weight, line-height.
    • Using external fonts from Google Fonts.
    • Four ways to write colors: named, RGB/RGBA, hexadecimal, HSL.
    • A first look at the browser Developer Tools.
    • You do not need to memorize every property. Use the internet for syntax. You will remember them with practice.
  2. CSS Font Properties
    • font-style: changes the look of the text. 
      p {
  font-style: italic;
}
    • font-size: makes the text bigger or smaller, usually in pixels. 
      p {
  font-size: 20px;
}
    • Why units? A number alone means nothing, like "speed is 20". It needs a unit (20 km/h, 5 km, 2 kg). In the same way, font size needs a unit, and px (pixel) is the common one.
    • A CSS pixel is 1/96 of an inch, which is about 0.26 mm. Other units (em, rem, %) come in later lectures.
    • font-family: each font family draws every letter in its own style. 
      p {
  font-family: cursive;
}
      Some families look almost the same as the default, so use an obvious one (like cursive) when testing.
    • Fallback system: you can list several families. If the first one is not available, the browser tries the next one, and so on. 
      font-family: "Open Sans", Arial, sans-serif;
    • Web safe fonts: fonts that already exist in almost every browser or device.
    • font-weight: how thick or dark the text is. Use numbers from 100 to 900.
      • 100 = very light
      • 400 = normal
      • 900 = very bold
    • line-height: the gap between two lines of text. 
      p {
  line-height: 30px;
}
      A bigger value gives more gap, a smaller value gives less gap.
  3. Using External (Google) Fonts
    • Use this when you want a font that is not already in the browser.
    • Steps:
      1. Go to the Google Fonts website and pick a font you like.
      2. Click the + (select style) button.
      3. Copy the <link> tags and paste them inside the <head> of your HTML. This imports the font.
      4. Copy the font-family line Google gives you and use it in your CSS (internal or external).
      <link href="https://fonts.googleapis.com/css2?family=Roboto&display=swap" rel="stylesheet">

p {
  font-family: "Roboto", sans-serif;
}
  4. CSS Colors
    • There are four main ways to add a color. In the lecture they were used on background-color and color (text color).
    • 1. Named colors: yellow, brown, blue. 
      #first-para {
  background-color: yellow;
  color: brown;
}
    • 2. RGB / RGBA: Red, Green, Blue values from 0 to 255 (never above 255). rgb(0, 0, 0) is black.
      • Example of a light blue: rgb(100, 109, 192)
      • A = Alpha: the transparency level of the color. 0 = fully transparent (no color visible), 1 = fully solid, and values in between are partly see-through.
      background-color: rgb(100, 109, 192);
background-color: rgba(0, 255, 0, 0.5);  /* half transparent green */
    • 3. Hexadecimal: starts with #, then six digits.
      • First two = Red, middle two = Green, last two = Blue.
      • #ffffff = white. #ff2323 = an orange-red shade.
      • You can add two more digits at the end for opacity (alpha). A lower value makes the color lighter.
      background-color: #ffffff;
background-color: #ff2323;
    • 4. HSL: Hue, Saturation, Lightness.
      • Hue: a color wheel from 0 to 360. 0 = red, 120 = green, 240 = blue.
      • Saturation: the intensity of the color, 0% to 100%. 100% = full color, 0% = no color.
      • Lightness: how light the color is, 0% to 100%. 100% = fully light (looks white), 0% = fully dark.
      background-color: hsl(0, 100%, 50%);    /* red */
background-color: hsl(120, 100%, 50%);  /* green */
    • Use a color picker (in the browser DevTools, VS Code, or Google) to create colors. It shows the hex, RGB, and HSL values for the same color, so you do not have to remember them.
    • In real projects, RGB and hex are used the most.
    • Homework: explore how the alpha value works in the HSL function (hsla).

  6. Developer Tools Overview
    • Right-click an element on the page and choose Inspect.
    • Elements tab: shows your HTML code. Hover over a line to highlight that element on the page, or click an element on the page to see its code (with its id and content).
    • Styles panel: shows the CSS properties applied to the selected element, for example background-color: yellow and color: brown.
    • You can click a value and change it to test things, such as changing yellow to green. You can also untick a property to turn it off.
    • Changes are temporary. They only exist in your own browser. When you reload the page, everything goes back to normal. Other people never see your changes, so you can safely edit any website's text or colors for testing.
    • User agent stylesheet: styles that the browser adds by default (like margin and display). You did not write them.
