Box Model

  1. What this lecture covers
    • Borders, height and width, the box model, padding, margin, and the universal selector.
    • Internal CSS is used in the lecture. Later lectures move to external CSS.
  2. Borders
    • A border needs three things: style, width, and color. 
      h1 {
  border-style: solid;
  border-width: 2px;
  border-color: brown;
}
    • Border styles: solid, dotted, dashed, and more. Pick the one you like.
    • Shorthand notation: write all values in one property (order: width, style, color). 
      h1 {
  border: 5px solid brown;
}
    • border-radius: rounds the sharp corners. A bigger value gives rounder corners. 
      h1 {
  border-radius: 5px;
}
      A very large value (like 50px) makes the box very round, and the text can look like it comes out of the box.
    • Round only one corner: use the corner properties. 
      h1 {
  border-top-left-radius: 5px;
  /* also: border-top-right-radius,
     border-bottom-left-radius,
     border-bottom-right-radius */
}
    • Border on only one side: 
      h1 {
  border-top: 5px solid yellow;
  /* also: border-bottom, border-right, border-left */
}
    • In the lecture, border: 3px solid black; and border-radius were applied to the heading and all the paragraphs, so every box looked the same.
  3. Height and Width
    • By default a block element takes the full width of the page (100%). You can set your own size. 
      p {
  width: 350px;
}

h1 {
  width: 350px;
  height: 200px;
}
    • Adjust the number until the box looks right (the lecture tried 500px, 300px, and then 350px).
    • You can set width and height separately for different elements.
    • Later lectures will compare block and inline elements.
  4. The Box Model
    • The browser shows every piece of content inside a rectangular box. It does not matter if the content is text, an image, a logo, a graphic, an ad, or a button. There are no circular or triangular boxes.
    • Keep the box model in mind whenever you design or plan a layout with CSS.
    • Every box has 4 layers, from the inside out:
      1. Content: the text, image, or other content itself.
      2. Padding: the space between the content and the border (inside the border).
      3. Border: the line around the padding and content.
      4. Margin: the space outside the border, between this box and other boxes (outside the border).
    • Easy way to remember:
      • Gap inside the border = padding
      • Gap outside the border = margin
  5. Box Model in DevTools
    • Right-click an element, choose Inspect, and look at the box model diagram in the Styles / Computed area.
    • When you hover over each layer, it is highlighted on the page with a color:
      • Blue = content (for example 350 x 110 px)
      • Green = padding (for example 90px on all sides)
      • Dark / black line = border (for example 3px)
      • Orange = margin (for example 90px)
    • It also shows the exact values for each of the four sides, so you can check your work.
  6. Padding
    • Padding is the space between the content and the border. It can be 0.
    • padding: 10px; adds space on all 4 sides. A bigger value gives more space (the lecture tried 10px, 50px, 90px).
    • One side at a time: 
      padding-left: 10px;
padding-top: 20px;
padding-right: 30px;
padding-bottom: 40px;
    • Four-value shorthand: the order is top, right, bottom, left (clockwise). 
      padding: 15px 25px 35px 45px;
/*       top  right bottom left */
    • Two-value shorthand: the first value is top and bottom (vertical), the second is left and right (horizontal). 
      padding: 20px 40px;
/* 20px top and bottom, 40px left and right */
    • Check every value with Inspect and the box model diagram.
  7. Margin
    • Margin is the space outside the border. It controls the gap between two boxes and how far a box is from the edge of the page.
    • margin: 50px; adds space on all 4 sides.
    • One side at a time: 
      margin-top: 100px;
margin-left: 20px;
margin-right: 20px;
margin-bottom: 20px;
    • Example: margin-top: 100px; pushes the box down from the top. Nothing is added on the left or right.
    • To increase the gap between two boxes, increase the margin.
  8. Universal Selector and Best Practice
    • Browsers add a small default margin (for example on the left and top of the page). You did not write it.
    • Best practice: remove the defaults first, then add your own spacing where needed.
    • The universal selector is the star *. It selects all elements on the page. 
      * {
  margin: 0;
  padding: 0;
}
    • After adding this, the gaps on the left, top, and between boxes disappear.
    • Selectors learned so far: element, ID, class, group, and now universal.
  9. Quick revision
    • Border = style + width + color. Shorthand: border: 5px solid brown;
    • border-radius rounds corners. You can round one corner or put a border on one side.
    • width and height set the size of a box.
    • Box model layers: content, padding, border, margin.
    • Padding = inside the border. Margin = outside the border.
    • Shorthand order for four values: top, right, bottom, left. For two values: vertical, horizontal.
    • * { margin: 0; padding: 0; } removes all default spacing.
    • Use Inspect to see the box model of any element.
