🌈 CSS Position: Revision Notes

📌 What it does

  • position decides how an element is placed on the page.
  • Used with top, left, right, bottom.

1. 🔵 Static (Default)

  • Normal flow.
  • top/left/right/bottom do nothing.

2. 🟢 Relative

  • Moves from its own normal position.
  • Old space is kept.
  • Used as an anchor for absolute children.
.box {
  position: relative;
  top: 100px;
  left: 200px;
}

3. 💗 Absolute

  • Used for overlapping elements.
  • Positioned relative to the closest positioned parent.
  • Removed from normal flow, so old space is lost.
.parent {
  position: relative;
}

.child {
  position: absolute;
  top: 10px;
  right: 10px;
}

4. 🟠 Fixed

  • Stays at one spot on the screen while scrolling.
  • Example: Chat button or contact button.
.btn {
  position: fixed;
  bottom: 20px;
  right: 20px;
}

5. 🟣 Sticky

  • Normal at first, then sticks while scrolling.
  • Needs an offset like top: 0.
  • Sticks only within its scrolling container.
.title {
  position: sticky;
  top: 0;
}

⚡ Fixed vs Sticky

  • Fixed: Stays on the screen while scrolling.
  • Sticky: Stays within its scrolling container.

📊 Quick Comparison Table

Value Relative To Old Space Kept?
Static Normal flow N/A
Relative Its own position Yes
Absolute Closest positioned ancestor No
Fixed Viewport (normally) No
Sticky Scroll container Yes
💡 Remember:
  • Absolute = Overlap
  • Fixed = Stays on screen
  • Sticky = Sticks while scrolling
  • Relative = Moves but keeps its space
